# Integraciones

Cámara/archivos: CameraX, Photo Picker/Storage Access Framework y manejo seguro de URI.

OCR: ML Kit para imágenes y páginas PDF renderizadas. Registrar versión, modelo, configuración y errores al implementarlo.

PDF: extraer texto directamente cuando sea posible; PdfRenderer + OCR para PDF escaneados. Documentar librería/licencia de extracción textual.

API de precios: BLOCKED hasta recibir documentación oficial. Registrar endpoint, autenticación, esquema, moneda, fecha, límites, licencia, términos y política de caché. No inventar contrato. Las respuestas son efímeras y no se almacenan. Si el proveedor exige persistencia, bloquear y solicitar decisión.
