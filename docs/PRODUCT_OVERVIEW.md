# Visión del producto

Estado inicial: PLANNED; contrastar con el código.

MarketCompare registra precios observados en compras reales mediante facturas y los compara con cotizaciones temporales de un proveedor API.

Principios: Android inicial; Kotlin Multiplatform + Compose Multiplatform; Material 3; uso local sin registro; revisión antes de guardar; trazabilidad de precio, cantidad, fecha, tienda y descuento; API externa separada y no persistida; preparada para sincronización futura sin implementar nube/login en el MVP.

Alcance previsto: importación de factura por cámara/imagen/PDF, OCR, revisión, compras locales, historial, comparación API efímera, normalización de productos, autocompletado y listas.

Fuera del MVP: login, backend propio, sincronización multi-dispositivo y persistencia de cotizaciones externas.
