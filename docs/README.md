# Documentación de MarketCompare

Índice y fuente de verdad documental. Actualizar en el mismo PR que el código afectado.

- `PRODUCT_OVERVIEW.md`: propósito, alcance y estado del producto.
- `ARCHITECTURE.md`: capas, dependencias y flujos.
- `FUNCTIONALITY.md`: funcionalidades y flujos de usuario.
- `DATA_MODEL.md`: entidades, relaciones, trazabilidad y persistencia.
- `DESIGN_SYSTEM.md`: Material 3, tokens y componentes.
- `PROJECT_CONFIGURATION.md`: versiones, Gradle, SDK, dependencias y comandos.
- `INTEGRATIONS.md`: OCR, PDF, cámara y API externa.
- `QUALITY_AND_TESTING.md`: estrategia y criterios de calidad.
- `CHANGELOG_TECHNICAL.md`: evolución técnica.
- `GLOSSARY.md`: términos del dominio.
- `DEVELOPMENT_GUIDE.md`: onboarding y contribución.
- `adr/`: decisiones arquitectónicas.

## Reglas
Leer antes de cambiar código; actualizar en el mismo PR; documentar estado real; usar IMPLEMENTED/PARTIAL/PLANNED/DEPRECATED; verificar nombres y comandos contra el repositorio. Documentación desactualizada bloquea el cierre de tareas.
