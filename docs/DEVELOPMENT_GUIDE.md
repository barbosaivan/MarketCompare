# Guía de desarrollo y onboarding

1. Leer README raíz y este índice.
2. Revisar reglas, arquitectura y ADR aplicables.
3. Inspeccionar Git y backlog.
4. Trabajar en rama de tarea.
5. Mantener cambios acotados y pruebas junto al código.
6. Actualizar documentación afectada en el mismo PR.
7. Revisar diff, build, tests, lint, strings, colores, accesibilidad y APIs deprecated.
8. Actualizar dashboard, backlog y changelog técnico cuando corresponda.
9. El PR debe indicar documentos actualizados y pruebas ejecutadas.
